# AI Image Generator Frontend

## Student Information

Name: Azka Maryam

Course: Web Engineering

## Project Overview

This project is a frontend implementation of an AI Image Generator application developed using React, Vite, Tailwind CSS, and React Router.

The application provides a modern user interface for an AI-powered image generation platform, including page navigation, user interaction components, and responsive layouts.

## Features Implemented

* Responsive Navigation Bar
* Login Modal
* Home Page
* Hero Section
* Description Section
* Steps Section
* Testimonials Section
* Footer
* Result Page
* Buy Credits Page
* React Router Navigation
* Tailwind CSS Styling
